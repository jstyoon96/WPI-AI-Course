# WPI Week 5 Lab 1

## Topic
Biomedical Segmentation Model Development

## Runtime
Use Google Colab. A GPU runtime is recommended because this lab trains a small
U-Net-style model on microscopy image-mask pairs.

## Student Deliverables
- Run the notebook cells in order.
- Complete the visible `TODO` prompts.
- Save and download `week5_outputs/best_unet.pt` for Lab 2.
- Submit `WPI_week5_lab1_responses_LastName_FirstName.docx`.

## Data
This lab downloads BBBC038 / 2018 Data Science Bowl nuclei segmentation data at
runtime and merges per-nucleus masks into a binary foreground mask. Do not
commit downloaded dataset files or model checkpoints.
