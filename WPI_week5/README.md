Week 5 uses the BBBC038 / 2018 Data Science Bowl nuclei segmentation dataset.
Dataset files are downloaded at runtime in Colab and are not stored in this
repository. Lab 2 uses the checkpoint produced by Lab 1, so students should save
or download `week5_outputs/best_unet.pt` before ending the Lab 1 Colab session.
